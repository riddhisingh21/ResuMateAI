ResuMateAI Project Analysis

Repository: riddhisingh21/ResuMateAI | URL: https://github.com/riddhisingh21/ResuMateAI
React Vite Clerk Gemini AI Strapi Tailwind CSS

What this project does

ResuMateAI is an AI-powered resume builder. It allows users to sign in, create multiple resumes, fill in their personal information, summary, work experience, education, and skills, generate AI-based content, preview the result, and download or share the final resume.

The project mainly solves the problem of making resume creation easier and more polished, especially for people who need strong professional wording quickly.

Tech stack

  • Frontend: React 18 + Vite
  • Authentication: Clerk
  • Styling: Tailwind CSS
  • AI: Google Generative AI (Gemini 1.5 Flash)
  • API backend: Strapi REST API
  • Routing: React Router DOM
  • UI features: Radix UI, Lucide icons, Sonner notifications

How it works

  1. The application starts from src/main.jsx and sets up routing.
  2. App.jsx checks whether the user is signed in using Clerk.
  3. If signed in, the user can access the home page and dashboard.
  4. The dashboard lists resumes using GlobalApi.js and the Strapi API.
  5. When a new resume is created, a UUID is generated and saved in the backend.
  6. The editor page loads resume data into ResumeInfoContext.
  7. Each form updates the shared resume state and saves it to the server.
  8. The preview page consumes the same state and shows a live resume layout.
  9. AI features call Gemini to generate summary and bullet point suggestions.
  10. The user can print, download, or share the final resume.

Workflow

1. User opens /auth/sign-in
2. Clerk login is completed
3. User navigates to /dashboard
4. Resume list is loaded from Strapi
5. User clicks “Create new resume”
6. Resume is added using POST /user-resumes
7. User is redirected to /dashboard/resume/:resumeId/edit
8. User fills personal details, summary, experience, education, skills
9. Data is updated using PUT /user-resumes/:id
10. ResumePreview shows live updates
11. User clicks Download or Share
12. Final resume is printed or shared by URL

Core files

  • src/main.jsx – route setup and app bootstrap
  • src/App.jsx – authentication guard and layout
  • src/dashboard/index.jsx – dashboard and resume list
  • src/dashboard/components/AddResume.jsx – create-new-resume flow
  • src/dashboard/resume/[resumeId]/edit/index.jsx – editing page
  • src/dashboard/resume/components/FormSection.jsx – multi-step form navigation
  • src/dashboard/resume/components/ResumePreview.jsx – final resume view
  • service/GlobalApi.js – API communication with Strapi
  • service/AIModal.js – Gemini API configuration
  • src/dashboard/resume/components/forms/Summary.jsx – AI summary generation
  • src/dashboard/resume/components/RichTextEditor.jsx – AI experience bullet generation
  • src/my-resume/[resume-id]/view/index.jsx – final share/download page

Important technical observations

  • The project is mostly frontend-driven; real data is stored in an external Strapi backend.
  • AI features depend on Gemini and JSON-based structured responses.
  • Clerk handles authentication and user identity.
  • The app uses React Context to synchronize form values and preview UI.
  • It includes print CSS to support PDF generation through browser print.

Possible interview questions and answers

1. What is ResuMateAI?

Answer:

ResuMateAI is an AI-assisted resume builder that allows users to create, edit, and preview professional resumes. It integrates AI to generate summaries and bullet points and stores user resume data in a backend service.

2. What are the main technologies used in the project?

Answer:

The app uses React, Vite, Clerk for authentication, Tailwind CSS for styling, Strapi for backend data storage, and Google Gemini for AI content generation.

3. How is user authentication handled?

Answer:

Authentication is handled by Clerk via the ClerkProvider and the useUser() hook. If the user is not signed in, the application redirects them to the sign-in route.

4. How does resume creation work?

Answer:

The dashboard uses the AddResume component to collect a title, generates a UUID, and sends the resume data to the backend using the CreateNewResume API function. Then the app navigates the user to the resume editor.

5. How does the app save resume data?

Answer:

Resume data is saved to Strapi using the GlobalApi wrapper. Each form sends payloads in the format { data: { ... } } using PUT requests to update a specific resume by ID.

6. What role does React Context play?

Answer:

React Context is used to share the current resume object between form components and the preview component. This allows the form and preview to stay in sync without passing data through many nested props.

7. How is AI used in the project?

Answer:

Gemini is used to generate a professional summary and experience bullet points based on a user's job title. The generated content is formatted and rendered inside the resume editor.

8. What is the purpose of GlobalApi.js?

Answer:

GlobalApi.js centralizes all API calls to Strapi. It exposes functions for creating, fetching, updating, and deleting resumes.

9. How is the final resume downloaded or printed?

Answer:

The view page calls window.print(), and CSS hides non-print elements while keeping only the resume content visible in print mode, making it suitable for PDF export.

10. What are the possible improvements?

Answer:

The project should move secret keys to a secure backend, validate ownership of resumes on the backend, sanitize AI-generated HTML, fix inconsistencies in field naming, and add tests and production security controls.

Short conclusion

ResuMateAI is a structured and practical AI resume builder project. It combines modern frontend development, API-driven data handling, AI-assisted content generation, and print/share workflows. It is a strong example of a real-world CRUD + AI application built with React and Vite.
